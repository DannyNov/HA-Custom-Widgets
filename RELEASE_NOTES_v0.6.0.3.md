# HA Custom Widgets v0.6.0.3

[Русский](#русский) · [English](#english)

## Русский

Первый публичный релиз нативных виджетов Home Assistant для Android.

### Основные возможности

- прокручиваемый и изменяемый по размеру HA Dashboard;
- вкладки «Главное», пространства Home Assistant и «Сценарии»;
- группировка, изменение порядка и точечное скрытие карточек и параметров;
- управление светом, розетками, переключателями и автоматизациями;
- выборочный ручной запуск автоматизаций и скриптов с отдельной кнопкой ▶;
- настраиваемые таймеры автоотключения Home Assistant;
- цветные индикаторы температуры, влажности и батареи;
- русский интерфейс для системной локали `ru`, английский для остальных;
- светлая и тёмная темы;
- прямой доступ к настройкам каждого экземпляра Dashboard.

### Установка

Скачайте `HAWidgets-v0.6.0.3.apk` и установите его на Android 8.0 или новее. При обновлении устанавливайте APK поверх предыдущей версии, не удаляя приложение.

Для подключения нужны адрес Home Assistant и Long-Lived Access Token. Необязательный Real-time режим требует системного доступа к уведомлениям; приложение не читает содержимое уведомлений.

Исходный код распространяется по лицензии Apache License 2.0.

## English

The first public release of native Android home-screen widgets for Home Assistant.

### Highlights

- scrollable and resizable HA Dashboard;
- Main, Home Assistant space and Scenarios tabs;
- grouping, manual ordering and individual visibility for cards and metrics;
- light, outlet, switch and automation controls;
- optional manual automation and script launch with a separate ▶ button;
- configurable Home Assistant auto-off timers;
- colored temperature, humidity and battery indicators;
- Russian UI for the `ru` system locale and English for every other locale;
- light and dark themes;
- direct settings access for each Dashboard widget instance.

### Installation

Download and install `HAWidgets-v0.6.0.3.apk` on Android 8.0 or later. Install updates over the previous version without uninstalling the app.

A Home Assistant URL and Long-Lived Access Token are required. Optional Real-time mode needs Android Notification access; the app does not read notification contents.
