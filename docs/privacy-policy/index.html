Privacy Policy — HA Custom Widgets

Effective date: September 6, 2026

HA Custom Widgets is an independent Android application developed by Danila Novikov for displaying and controlling user-configured Home Assistant entities through Android home-screen widgets.

This Privacy Policy explains how HA Custom Widgets accesses, processes, stores, and transmits information.

1. Data collection

HA Custom Widgets does not collect personal data for the developer.

The application does not use analytics, advertising SDKs, tracking services, or a developer-operated server for processing Home Assistant data.

The developer does not receive your Home Assistant URL, access token, entity states, device information, or other Home Assistant data.

2. Home Assistant connection

To use the application, the user provides:

  • a Home Assistant server URL;
  • a Home Assistant Long-Lived Access Token.

These credentials are used only to establish a direct connection between the user's Android device and the Home Assistant server specified by the user.

Home Assistant data processed by the application may include entity names, entity states, attributes, areas, devices, sensors, automations, scripts, timers, and other information made available by the user's Home Assistant instance.

This information is used only to provide the application's widget, display, configuration, and control functionality.

Home Assistant data is not routed through servers operated by the developer.

3. Local storage and security

Application configuration is stored locally on the user's Android device.

The Home Assistant access token is protected using AES-GCM encryption with key material managed by the Android Keystore.

Android application backup is disabled for HA Custom Widgets to reduce the risk of transferring stored credentials through device backup.

Users are strongly encouraged to connect to Home Assistant using HTTPS and to use an appropriately restricted Home Assistant user account.

4. Notification access

HA Custom Widgets may optionally request Android Notification Access.

Notification Access is used to help maintain the Home Assistant event connection while the application operates in the background.

HA Custom Widgets does not use Notification Access to collect, store, analyze, transmit, or share the contents of the user's notifications.

The user may choose not to grant Notification Access. Core application functionality and manual refresh remain available, although background updates may be less reliable.

5. Data sharing

HA Custom Widgets does not sell user data.

The developer does not share Home Assistant credentials, Home Assistant data, notification contents, or other personal data with advertisers, analytics providers, data brokers, or other third parties.

Network communication with Home Assistant is sent directly to the Home Assistant server configured by the user.

6. Data retention and deletion

Home Assistant connection information and application settings remain locally on the user's device for as long as they are required by the application.

The developer does not maintain a server-side copy of this information.

Users can remove locally stored application data by clearing HA Custom Widgets application data or uninstalling the application.

A Home Assistant Long-Lived Access Token can also be revoked at any time from the user's Home Assistant account.

HA Custom Widgets does not create or manage Home Assistant user accounts. Deletion of Home Assistant accounts and data stored by Home Assistant is controlled by the user's Home Assistant installation.

7. Children's privacy

HA Custom Widgets is a general-purpose Home Assistant utility and is not specifically designed for children.

The application does not knowingly collect personal information from children or other users.

8. Changes to this Privacy Policy

This Privacy Policy may be updated when the application's functionality or data-handling practices change.

The effective date at the top of this page will be updated when material changes are made.

9. Contact

For privacy questions or other inquiries regarding HA Custom Widgets:

Developer: Danila Novikov
Email: hacustomwidgets@gmail.com

HA Custom Widgets is an independent project and is not affiliated with or endorsed by Home Assistant or the Open Home Foundation.

Политика конфиденциальности — HA Custom Widgets

Дата вступления в силу: 6 сентября 2026 г.

HA Custom Widgets — независимое Android-приложение, разработанное Данилой Новиковым для отображения и управления настроенными пользователем сущностями Home Assistant с помощью виджетов на домашнем экране Android.

Настоящая Политика конфиденциальности описывает, как HA Custom Widgets получает, обрабатывает, хранит и передаёт информацию.

1. Сбор данных

HA Custom Widgets не собирает персональные данные для разработчика.

Приложение не использует аналитику, рекламные SDK, системы отслеживания или сервер разработчика для обработки данных Home Assistant.

Разработчик не получает URL вашего Home Assistant, токен доступа, состояния сущностей, сведения об устройствах или другие данные Home Assistant.

2. Подключение к Home Assistant

Для работы приложения пользователь указывает:

  • адрес сервера Home Assistant;
  • Long-Lived Access Token Home Assistant.

Эти данные используются только для прямого соединения Android-устройства пользователя с указанным им сервером Home Assistant.

Обрабатываемые приложением данные Home Assistant могут включать названия и состояния сущностей, атрибуты, помещения, устройства, показания датчиков, автоматизации, скрипты, таймеры и другую информацию, предоставляемую экземпляром Home Assistant пользователя.

Эта информация используется исключительно для отображения, настройки и управления функциями приложения и виджетов.

Данные Home Assistant не передаются через серверы разработчика.

3. Локальное хранение и безопасность

Настройки приложения хранятся локально на Android-устройстве пользователя.

Токен доступа Home Assistant защищается шифрованием AES-GCM с использованием ключевого материала, управляемого Android Keystore.

Резервное копирование Android для HA Custom Widgets отключено для снижения риска переноса сохранённых учётных данных через резервные копии устройства.

Пользователям рекомендуется подключаться к Home Assistant по HTTPS и использовать учётную запись Home Assistant с необходимым минимальным уровнем доступа.

4. Доступ к уведомлениям

HA Custom Widgets может дополнительно запросить системный доступ Android к уведомлениям.

Этот доступ используется для поддержания соединения с событиями Home Assistant при фоновой работе приложения.

HA Custom Widgets не использует доступ к уведомлениям для сбора, хранения, анализа, передачи или распространения содержимого уведомлений пользователя.

Пользователь может не предоставлять этот доступ. Основные функции приложения и ручное обновление остаются доступны, однако фоновые обновления могут работать менее надёжно.

5. Передача данных

HA Custom Widgets не продаёт пользовательские данные.

Разработчик не передаёт учётные данные Home Assistant, данные Home Assistant, содержимое уведомлений или другие персональные данные рекламным сетям, аналитическим сервисам, брокерам данных или иным третьим лицам.

Сетевое взаимодействие с Home Assistant осуществляется непосредственно с сервером Home Assistant, указанным пользователем.

6. Хранение и удаление данных

Данные подключения к Home Assistant и настройки приложения хранятся локально на устройстве пользователя, пока они необходимы приложению.

Разработчик не хранит серверную копию этих данных.

Пользователь может удалить локально сохранённые данные, очистив данные приложения HA Custom Widgets или удалив приложение.

Long-Lived Access Token можно в любое время отозвать в учётной записи Home Assistant пользователя.

HA Custom Widgets не создаёт и не управляет учётными записями Home Assistant. Удаление учётных записей и данных Home Assistant осуществляется средствами экземпляра Home Assistant пользователя.

7. Конфиденциальность детей

HA Custom Widgets является универсальной утилитой для Home Assistant и не предназначено специально для детей.

Приложение сознательно не собирает персональную информацию детей или других пользователей.

8. Изменения Политики конфиденциальности

Политика может обновляться при изменении функций приложения или способов обработки данных.

При существенных изменениях дата вступления политики в силу, указанная в начале страницы, будет обновлена.
