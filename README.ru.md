# HA Custom Widgets

[English version](README.md)

Нативные Android-виджеты для Home Assistant. Имена сущностей и устройств остаются такими, как их передаёт Home Assistant. При русском языке телефона интерфейс русский, при любом другом — английский.

## Основные возможности v0.6.0

- прокручиваемый HA Dashboard с вкладками «Главное», пространствами и сценариями;
- группировка, порядок и видимость карточек и параметров;
- крупные кнопки питания для основных сущностей `light` и `switch`;
- настраиваемые таймеры Home Assistant, включая 120 минут;
- цветные индикаторы температуры, влажности и заряда;
- точечное скрытие автоматизаций и скриптов;
- отдельное разрешение запуска каждого сценария с индикацией ожидания, успеха и ошибки;
- русский и английский интерфейс;
- добровольная поддержка через CloudTips или USDT (BEP-20 / TON).

Запуск автоматизации не обходит её условия (`skip_condition=false`). Зелёная кнопка означает, что Home Assistant принял вызов, а не гарантирует завершение всех физических действий.

## Безопасность и сборка

Адрес и токен Home Assistant не находятся в исходном коде. Токен шифруется AES-GCM ключом Android Keystore, резервное копирование отключено. Для внешнего доступа предпочтителен HTTPS и отдельный пользователь HA с минимальными правами.

Требуются JDK 17, Android SDK 35 и Gradle 8.9:

```bash
gradle testDebugUnitTest assembleDebug
```

Release workflow создаёт подписанный APK без `debuggable`. Ключ поступает только через GitHub Actions Secrets и не хранится в Git.
