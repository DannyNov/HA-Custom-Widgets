# v0.6.4-rc1 — Pre-release

- Timer cards reserve countdown space so inactive/start/stop/expiry and 30/60/90/120-minute presets keep a stable height. Space adapts to width and font size.
- Each Dashboard can hide the Favorites tab in its settings. Enabled by default; saved favorites are retained. Hiding the selected tab switches to the first ordinary tab in the saved order. With no ordinary tabs, a prompt asks the user to choose tabs in settings.
