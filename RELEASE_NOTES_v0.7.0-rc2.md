# HA Custom Widgets v0.7.0-rc2

Corrective visual Pre-release based strictly on published v0.7.0-rc1 (afece5e292314a145d4822d7702b992f0f05be1f), guided by the user's real Honor screenshots.

- Temperature capability contours are more readable on the dark Dashboard: amber, cream, neutral white and cool blue, without changing contour geometry. The successful rainbow palette and brightness-only capsule remain unchanged.
- Brightness, temperature and color now share a 10dp rounded track, matching available width and 48dp minimum interaction area. Brightness and temperature use compact matching 20dp circular thumbs. The color bar retains tap/hold behavior and has no draggable thumb.
- Parameter labels and current values share a compact header row when space permits; narrow windows and large fonts reflow safely. Temperature preset values remain centered and reachable.
- The picker uses the same slider style. RC1 capabilities, Kelvin ranges/clamping, canonical HS, restore/picker behavior, realtime handling and serialization remain unchanged.

Physical Honor verification is required before Final: compare temperature/rainbow/dual contours; check the unified tracks, circular thumbs, headers and presets; resize and increase font size; run quick brightness/temperature/color/Power/realtime checks.

RC only: no Final, main/stable merge, Telegram announcement or force-push. RC1 and previous releases remain available.
