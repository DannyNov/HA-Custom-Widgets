## Русский

- Управление яркостью dimmable lights прямо из Dashboard: `− / % / +`, шаг ±5 процентных пунктов.
- Нажатие на `%` открывает компактный Slider. Выбор стабилизирован; значение отправляется после завершения выбора.
- Capsule/outline для кнопок яркости и согласованное оформление активного состояния.
- Плавающее окно Slider со скруглением, аккуратными отступами и компактной шириной. Вспомогательная Activity не появляется в Recents.
- Жёлтые значки активных Power и Timer там, где это применимо.
- Улучшенная компоновка Timer/Power: interval и countdown начинаются на одной вертикали, положение подписей не меняется с длиной текста.
- В README описана уже существующая возможность нескольких независимо настроенных Dashboard и добавлен реальный скриншот с тремя экземплярами. Подключение к Home Assistant остаётся общим.

Android 12+. Установите APK поверх предыдущей версии, не удаляя приложение, чтобы сохранить настройки.

## English

- Control dimmable light brightness directly in Dashboard with `− / % / +`, in ±5 percentage-point steps.
- Tap `%` to open a compact Slider. Selection is stabilized and the value is sent after selection finishes.
- Capsule/outline brightness controls with consistent active-state styling.
- A rounded floating Slider window with improved padding and compact width. Its helper Activity stays out of Recents.
- Yellow active Power and Timer glyphs where applicable.
- Improved Timer/Power layout: interval and countdown labels share the same left edge and stay in place as text length changes.
- The README documents the existing ability to configure multiple Dashboard instances independently, with a real screenshot showing three widgets. The Home Assistant connection remains shared.

Android 12+. Install the APK over your current version without uninstalling to preserve settings.
